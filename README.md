# Eduardo's website

Personal blog, activities tracker, travelling goals, resume and portfolio.

## Dev

```bash
bun install
bun dev
```

## Build

```bash
bun run build
```

## Stack

- Next.js 16 (App Router, static export)
- React 19, TypeScript 5
- Tailwind CSS v4
- Bun
- three.js + three-globe
- Matter.js
- Cloudflare Workers
- GitHub Page/Actions
